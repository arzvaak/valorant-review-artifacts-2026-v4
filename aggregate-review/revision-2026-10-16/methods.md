## Rating extension specification v1

- Primary references: Glickman, https://glicko.net/glicko/glicko2.pdf (22 March 2022 technical specification); Herbrich, Minka and Graepel, https://proceedings.neurips.cc/paper_files/paper/2006/file/f44ee263952e65b3610b8ba51229d1f9-Paper.pdf. The 1999 Glickman paper is foundational but not the exact Glicko-2 numerical specification.
- Team Glicko-2: initial original-scale mean 1500, deviation 350, volatility .06, tau .5, epsilon 1e-6. Equal-release batches are rating periods; inactive time is measured in elapsed days. Inflate deviation by sigma^2 times max(elapsed_days-1,0) before the period, then apply the published one-period volatility/update rule. Predictions integrate elapsed uncertainty without changing the stored mean. Report this rating-period adaptation explicitly, including sparse batches; do not claim this is the author's recommended 10–15-games-per-period setting.
- Predictive team probability is the symmetrized mean of the two directed Glicko expectations, so swapping canonical slots complements probability exactly. Both task states are separate.
- Player reference: binary, no-draw diagonal Gaussian team-sum assumed-density updates from the TrueSkill model, implemented with PyTorch float64 on CUDA. Default mu 25, sigma 25/3, beta 25/6, tau 25/300 per elapsed day. Equal-release posterior messages combine in natural-parameter space from frozen pre-batch distributions. This is a declared diagonal, simultaneous-message implementation, not full iterative EP for a multi-game factor graph.
- Map uses the observed admissible five-player lineup. Series uses the last unambiguous strictly prior released map appearance for each team. Missing/incomplete proxies fall back to the same task's team Glicko-2 probability; no actual future lineup is substituted. Player state updates require full admitted input rosters, retained from prediction time; map appearances can update proxy rosters only at release. Separate task player skills.
- K20 reference included under exactly the same newly declared availability/calibration policies, with stored pre-prediction expectations and summed equal-release increments. Preserve the existing published K20 comparisons separately.
- Compare training-only two-hour state and all-eligible-prior six-hour state. Common calibration is fitted on each original separate calibration partition via nonnegative scalar logit scale, same minimum five-event/two-class rule; report raw and calibrated ratings. No evaluation-based parameter selection.
- Record per-source keys/label identities, exact lineup/map inventory from whitelisted database query and global/protected exclusions. Complete predictions for all original phase keys before scoring this extension; retain original known outcomes only under chronological state rules. Fail closed without CUDA or on unresolved volatility/numerical errors.
- No hyperparameter search: defaults fixed above. New rating outputs are separate from all original frozen results. Save completed task/regime units and failure receipts. Paired evaluation uses the existing valid broad/reviewed scopes and complete-event proper-loss summaries.

- Additional matched-refresh comparison: frozen training-only state with the same six-hour availability delay as online state. Both receive the same separate-event calibration policy. This comparison holds the rating algorithm, availability delay and calibration fitting rule fixed; history admission is the changed factor. Original two-hour frozen histories remain a separate regime.


## Controlled player representation extension v1

- Consume the original fold arrays and a separate correction of only six side-headshot player channels. Correction queries only each block's admitted training Game IDs, keeps conflict/missingness explicit, and checks the exact original history-end cutoff for every target. Other numeric/composition/tensor fields remain unchanged. Corrected raw fields exist in the source warehouse; the availability inventory records 993758 nonnull training-side cells in block 12.
- Main controlled matrix uses corrected tensors: BN, BNC, BNL, BNLC × sum, mean, attention and summary pooling × both horizons × twelve original blocks × seeds 20261009/10/11. Sparse blocks retain the original minimum-five-event stopping/selection eligibility rule and K20 fallback. No evaluation-based block exclusions.
- All pools share a per-player two-layer MLP (64 hidden units, ReLU, dropout .1). Sum, mean and single-query softmax attention return one 64-dimensional vector per side and share the same two-layer 128-unit prediction head. Summary concatenates per-side mean, standard deviation, maximum and top-two means of the SAME encoded player tensors; its wider head and parameter count are disclosed as a complete-procedure control.
- Numerical input/missingness preprocessing is fitted only on mirrored training data. General player inputs are overall + recent + exposure; L adds the historical linked channel; C independently adds composition/map and per-player agent categories. This removes the old full-mode coupling of agent categories with linked channels. No current-series observed roster/agent substitution.
- Train on mirrored sides/labels; inference symmetrizes swapped probabilities. AdamW lr .0003, weight decay .001; at most 64 epochs, stopping patience 8, minimum stopping log-loss improvement 1e-6. Initial CUDA batch 1024; on a retained OOM attempt halve through 128; do not change architecture or search scope after seeing results. BF16 mixed precision with float32 logits/loss. Record parameter counts, actual batches, every epoch telemetry and checkpoint; completed seeds remain reusable by exact identity.
- The same configuration, optimization/stopping budget and three seeds apply to every condition. This is a controlled fixed-recipe sensitivity, not an assertion that each architecture received an individually optimized search. Distinct C/L contrasts hold pooling and projection fixed.
- Headshot repair sensitivity: additionally fit original uncorrected BNLC tensors under the same sum-pooling recipe/seeds, comparing with corrected BNLC sum. It isolates projection within that declared procedure; it is not a universal architecture claim.
- Calibrate the three-seed mean on the original separate calibration events, with the existing nonnegative scalar policy and sparse identity rule. Freeze all probabilities before scoring the extension. All adverse/unresolved arms are retained. New contrasts have their own complete inventory; original primary/player/removal inference stays unchanged.
