# Figure reproduction scope

This package displays saved aggregate development results only. Core comparisons retain 152 contrasts, player comparisons 48, and removals 40. Online graphics use four broad nonglobal accuracy contrasts from a complete 60-contrast source table. Source reports and adapter methods remain separate research evidence.

The core probability-loss contrasts use event-equal losses and pointwise complete-event saved-fit intervals. Corrected decisions retain the original inference families. Intervals are not simultaneous and omit refitting uncertainty. The online intervals are unadjusted exploratory development evidence. Dependence, adaptive analysis, source timing/roster proxies and population coverage remain limitations.

B denotes context, N general numeric histories, C agent and map channels, and L linked histories. C is not a pure agent-composition effect. Nonsignificance does not establish equivalence. The chronology diagram is schematic rather than measured publication timing.

No predictive model, raw source response, row-level outcome, contact address or credential is required to regenerate these graphics. Figure reconstruction does not refit models, recompute bootstrap inference, independently validate forecast arithmetic, or independently replicate a scientific finding.
