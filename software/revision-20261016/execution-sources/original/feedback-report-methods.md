# Retained continuation feedback method

## Inputs and source admission

Original later contexts, original valid targets, retained twelve model binaries, thresholds and calibrators remain unchanged. The original score-only continuation is the reference. Archived event-header Region evidence is bound by exact event ID and physical capture hash. Eighteen explicit regional-source events are admitted for feedback; five events with an unresolved global flag or a Location-only header remain score-only. This decision does not assign a professional tier/circuit or place unknown events into the reviewed regional populations.

All 1613 maps and 734 series from the same 23 events remain evaluation targets, regardless of their feedback status. Invalid target rows never enter feedback. Model weights, thresholds and probability calibrators are never fitted/selected using the later cohort. Outcomes are admitted only when scheduled anchor + six hours is strictly before the next prediction cutoff; equal-time forecasts are frozen before updates. This is a retrospective retained-procedure diagnostic, with original labels already known, and makes no new prospective-blindness claim.

## Refreshed information

Dynamic team/player/roster/map/agent states and K20/prior references follow the original numerical update rules. Rich residual inputs additionally receive the available admitted overview statistics (ACS/ADR/KAST/star and rate summaries), observed round-derived pistol/follow-up summaries and recent ACS variation/trend through the original history builder. Other inherited numeric/composition/linked channels retain their original block-local rules. All new map/player data remain linked to historical agent/map identities.

Retained overview captures do not provide a reviewed projection of all equipment, buy and ECON sections. Those missing observations stay unavailable; old lifetime summaries retain only their observed denominators. Do not call this a complete recovery of every missing raw-source statistic. Every field exclusion/projection failure is recorded; source absence and projection absence are distinguished.

The v1 performance projection rejected source empty future-round placeholders as ambiguous winners. V2 recognizes only structurally empty, title-free, image-free cells as placeholders; it never guesses a winner. Played round indexes must still be contiguous, and the derived winner must agree with the frozen target. V1 and its quarantines remain preserved.

Preserve original target-freeze provenance instead of pretending those targets were extracted after the new predictions. New comparisons are a separate exploratory family. Source-admission coverage and acquired player/roster coverage accompany performance changes; no cause is attributed to old weights or all cold-start effects from this comparison alone.

Complete new feedback family: four retained arms (rich residual, original residual, dynamic strength, K20) × two horizons × two probability losses = 16 contrasts. Use the original centered-event-bootstrap tail, a simultaneous 99% Monte Carlo upper bound (budget 16), and Holm across all 16; provide pointwise intervals alongside these exploratory corrected decisions. Event and row accuracy use the same complete-event draws and ratio weighting, reported descriptively. New rating references were declared only for the original twelve-block benchmark; they have no later retained-weight continuation contract and are not silently substituted into this family.
